# Telegram-Bot
AI Telegram Bot (GigaChat + Docker Stack)
###Профессиональный Telegram-бот на базе GigaChat с продвинутой архитектурой.

О проекте:
  Это не просто скрипт для общения с нейросетью, а полноценное масштабируемое приложение. Бот интегрирован с экосистемой GigaChat и оптимизирован для работы под нагрузкой.

🚀 Ключевые особенности (Технический стек):
  Core: Python 3.11+ / Aiogram 3 (современный асинхронный фреймворк).

  AI Engine: Интеграция с GigaChat API (Lite/Pro/Max модели).

  Brain (FSM): Использование Redis для хранения контекста диалога. Память бота не стирается при перезагрузке сервера.

  Database: PostgreSQL (через асинхронный драйвер asyncpg) для хранения профилей пользователей, статистики запросов и логов.

  Infrastructure: Полная контейнеризация через Docker & Docker Compose. Запуск всей системы (Бот + БД + Redis) одной командой.

  Analytics: Встроенная система мониторинга (время ответа ИИ, подсчет токенов, логирование транзакций).

🛠 Что реализовано в коде:
  Надежность: Использование транзакций в БД для сохранения целостности данных.

  Экономия: Механизмы эффективного управления контекстом (хранение истории сообщений в JSON-формате в Redis).

  Безопасность: Работа с переменными окружения через .env файлы.
